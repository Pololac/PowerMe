# MEMORY

## 2026-10-28 — Frontend security routine (manual)
- npm 10.9.x crashes on `npm audit fix` (`Cannot read properties of null (reading 'edgesOut')`,
  arborist `#loadPeerSet`, optional peer `canvas` of jsdom). Workaround: `npx --yes npm@11 audit fix`
  (no global install). npm 12 requires Node >= 22.22.2.
- `npm audit fix` took the frontend from 43 to 1 advisory; the last one (maplibre-gl <= 6.4.0, XSS
  sanitizer bypass) required the 5.x -> 6.x major upgrade.
- maplibre-gl 6 is ESM-only: namespace import (`import * as maplibregl`), `setWorkerUrl()` is mandatory
  with a bundler, and `maplibre-gl-worker.mjs` + `maplibre-gl-shared.mjs` are copied as assets in
  `angular.json`. Verified manually on `/map` (tiles, geolocation, markers from the backend).
- Backend failed to start with "No qualifying bean UserMapper": `target/` contained a `UserMapperImpl`
  generated by an IDE compiler (Eclipse JDT, Java 25). Fixed with `./mvnw clean compile`.
- `docker-compose.dev.yml` no longer exists: the dev DB is started from `deploy/docker-compose.yml`
  (service `db`, profile `backend`) with `--env-file .env.dev`. README.md still references the old file.
